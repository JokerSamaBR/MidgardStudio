## Upload rápido

1. Abra [screenshots no GitHub](https://github.com/JokerSamaBR/MidgardStudio/tree/main/screenshots).
2. Clique em **Add file → Upload files**.
3. Renomeie seus três PNGs conforme a tabela acima **antes de enviar** e confirme o commit na branch `main`.
4. O README do repositório já aponta para esses nomes e passará a exibir as imagens após o upload.
5. O cadastro do Midgard Studio no portal WYO também referencia os mesmos caminhos, mas a exibição depende do frontend do portal.

**Regras:** somente capturas verdadeiras do executável do usuário. Não usar banners antigos, imagens criadas artificialmente, sprites ou exemplos de outra edição. Não alterar a resolução nem adicionar marcações. Antes do upload, conferir visualmente os três arquivos para evitar imagens quebradas.
